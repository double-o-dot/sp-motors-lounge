# SP Motors 대기실 — 비 오는 날의 집중 공간

비 오는 날, 정비소 대기실에서 차를 맡겨두고 집중하는 뽀모도로 타이머입니다.

1. **접수 키오스크** – 정비 항목을 고르면 기본 집중 시간이 정해져요.
2. **작업지시서** – 차량번호와 집중/휴식 시간을 정해요.
3. **대기실** – 리프트 위 차, 일하는 정비사, 셔터 밖 비, TV 정비 현황판과 함께 집중해요. 휴식 시간에는 차가 내려오고 정비사도 커피를 마셔요.

- 라디오: Google Gemini로 생성한 연주곡 4곡 (`music/`)
- 환경음: 빗소리 · 작업장 공구 · 지나가는 차 · 히터 (Web Audio로 실시간 합성)
- 단축키: `Space` 일시정지/재생, `N` 다음 곡

빌드 없이 `index.html` 하나로 동작합니다. GitHub Pages로 배포돼 있어요.
